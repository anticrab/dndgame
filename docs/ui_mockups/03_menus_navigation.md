# 03 — Меню и навигационные экраны (ASCII-мокапы)

Эта серия мокапов покрывает все служебные экраны TUI: главное меню,
визард создания персонажа, save/load, settings, pause, диалог с NPC,
исследование, инвентарь, hand-over, тосты, сводку hot-keys.

Соглашения:

- Псевдографика: `═║╔╗╚╝`, `─│┌┐└┘├┤┬┴┼`, `░▒▓█`. Без эмодзи.
- Тема `color` — по умолчанию. В мокапе цвет дан комментарием рядом
  (cyan/yellow/red/grey/...). В `monochrome` тема сводит цвет к
  bold/dim/inverse — отдельно мокап не дублируется, в подписи к экрану
  отмечаются изменения.
- Раскладки: 80×24 (минимум), 120×40 (стандарт), 160×50+ (расширенный).
- Базовый язык — EN; параллельно показан RU. Если RU-вариант идентичен
  по структуре — только меняется текст внутри тех же рамок.
- Имена в примерах — из `SCENARIO_DEMO.md` (Тихий Брод, Гнилой Дуб,
  староста, Аэлар, Сила) и из тестовой колоды (Fighter/Rogue, Soldier).

будущие — пустые `░`. Кнопки `[Back]` `[Next]` `[Cancel]` всегда внизу.

## Заметки и нюансы

- В `monochrome` тема: подсветка активного пункта — `inverse video`,
  предупреждения (Point Buy <0, hostile NPC) — `bold` + префикс `!`,
  заблокированные пункты — `dim` + суффикс `[locked]` или `[недоступно]`.
- Везде, где есть `[Edit]`/`[Save]`/`[Cancel]` — это интерактивные
  кнопки Textual (focus-обводка не нарисована, подразумевается ярче-рамка
  у активной).
- Меню мастера и hot-seat — заглушки. Кнопки/пункты присутствуют как
  `[locked]` / «недоступно в MVP» — чтобы пользователь видел направление
  развития; код-каркас при этом уже есть (`UI.md` §6 row MasterScreen).
- Локали RU используют сокращённые маркеры (`ур.`, `СИЛ/ЛОВ/ТЕЛ` и т.п.),
  чтобы помещаться в 80-колоночные раскладки (требование `I18N.md` §7).
- В шаге Random Random использует `4d6kh3` (см. `DESIGN.md` §6 шаг 3);
  history показывает сырые броски, как требует `ENGINE.md` §7.3 (поле
  `raw`).
- Версии сохранений: формат `vN` в превью соответствует
  `Scenario.version` из `DESIGN.md` §12. Не та же сущность, что версия
  билда игры, и это намеренно — сохранение умирает при апдейте сценария
  до того, как Q12 закроется.
