# 02 — Character Sheet (TUI mockups)

Лист персонажа в TUI. Пять вкладок, два размера локали, три размера терминала.
Базовый язык — английский, RU — переключаемая локаль. Темы: `color` (по
умолчанию) / `monochrome`. В мокапах ниже цвет фиксируется комментарием
`# color:` под блоком. Псевдографика только из набора `═║╔╗╚╝ ─│┌┐└┘├┤┬┴┼ ░▒▓█`.

Образцы PC, используемые в мокапах:

- **Aelar** — Human Fighter 1, Soldier, Lawful Good. Базовый пример из
  `SCENARIO_DEMO.md`. На всех вкладках, если не сказано иначе.
- **Sila** — Elf Rogue 2, Criminal, Chaotic Neutral. Вариация для Spells &
  Features (видно полное отсутствие ячеек заклинаний у плута 2-го ур.) и для
  раздела «другие PC видят».

## Раздел B. Вкладки — полные мокапы

Для каждой вкладки: 80×24 EN, 80×24 RU, 120×40 EN, 120×40 RU, 160×50 EN,
160×50 RU. Все мокапы — точные по ширине.

> Условные обозначения:
> - `●` — владение (proficient), `○` — нет владения.
> - `◐` — экспертиза (двойной БМ), только Bard/Rogue.
> - `■` — израсходованная ячейка заклинания, `□` — доступная.
> - Death save success/fail точки — `●` / `○` × 3.
> - `▆ ▅ ▄ ▃ ▂ ▁` — высоты столбцов гистограммы d20.

## Открытые вопросы и заделы

Эти пункты вне скоупа документа, но всплыли при рисовании — внесены сюда,
чтобы не потерять:

1. **Прогресс-бар XP** (`▰▰▰▰▰▱▱▱▱▱`) — 10 ячеек, выбран фиксированный
   масштаб. Если уровни выровнять под `fast`-кривую (`PROGRESSION.md` §1.2),
   1 ячейка ≈ 10% до следующего уровня — работает для любой нелинейности.
2. **Сторонняя сводка экипировки** для бота-наблюдателя/мастера — пока не
   рисуем (см. `MASTER.md`).
3. **«By context» подсчёт бросков** в Journal на 160×50 — поле, которое
   `DiceStatisticsService` пока не считает по контекстам; запишем как
   расширение в `ENGINE.md` §7.
4. **NPC Relationships блок** в Bio (160) — поведение/значения числовые,
   но `DESIGN.md` §8.4 описывает только enum `friendly/neutral/hostile`.
   Числа в мокапе — иллюстративные; решить, ввести ли «рейтинг отношений»
   как отдельную фичу.
5. **Hot-seat full-sheet request** (`[F]` на mini-card) — UI-протокол
   запроса/разрешения не описан в `UI.md` §8; добавить туда.
