# DEMO — сценарий «первичного показа»

Минутный показ рабочего движка для защиты/презентации. Сцена `demo_skirmish`:
бывалый воин 1-го уровня против двух гоблинов в зале. Демонстрирует весь
реально работающий цикл и фирменный момент — **level-up прямо в бою**.

> Почему два гоблина, а не «толпа»: по правилам книги соло-персонаж 1-го
> уровня против 4–5 гоблинов — заведомо смертельный бой (это честная математика
> D&D, без послаблений). Чтобы показать level-up в бою на одиночке, воин —
> «бывалый» (стартовый XP 90, у порога 2 уровня, как после пары стычек из
> канона `SCENARIO_DEMO`): первое же добивание перешагивает порог. Бой при этом
> остаётся честным и надёжно проходимым.

## Запуск

```bash
dnd play demo_skirmish --tui     # ретро-TUI (рекомендуется)
dnd play demo_skirmish           # классический CLI (rich-лог)
```

## Что показывает

| Фича движка | Где в демо |
|---|---|
| Инициатива, пошаговый бой | старт боя |
| Движение и атаки на сетке | `m` (движение), `a` (атака) |
| Retro-TUI (карта, спрайты, action-bar, лог) | весь экран |
| AI монстров | ходы гоблинов |
| XP за убийства | после убитого гоблина |
| **Level-up в середине боя** | на 1-м убийстве (90+25=115 XP) — окно прокачки |
| Классовая фича после уровня | Action Surge (`x`) после 2 уровня |
| Спасброски от смерти (страховка) | если воин уйдёт в 0 HP |

## Ход показа (что говорить и нажимать)

1. **Старт.** «Бывалый воин 1-го уровня, два гоблина. Бросок инициативы —
   порядок ходов в панели справа.»
2. **Сближение.** `m`, навести курсор, подтвердить — воин идёт к ближайшему
   гоблину.
3. **Первый удар.** `a`, выбрать цель — воин (длинный меч +5) обычно ваншотит
   гоблина (7 HP).
4. **Level-up (кульминация).** Это добивание даёт +25 XP (90→115) и
   перешагивает порог: всплывает окно «Вы достигли 2 уровня!» — выбрать
   **«Сейчас!»**. Воин получает +HP и **Action Surge** прямо в бою. «Это и есть
   фишка коротких партий — прокачка в драматический момент.»
5. **Добивание.** `x` (Action Surge — лишнее действие) и `a` — добить второго
   гоблина. **Победа** (`EncounterEnded`, партия победила).

## Если что-то пойдёт не так

- Воин упал в 0 HP — он не умирает мгновенно (спасброски от смерти, пипсы
  в оверлее). Это тоже часть демонстрации, а не баг.
- Броски невезучие — бой по чистым правилам книги, исход честный; перезапустить
  командой запуска.
